# AI Handover Index

Protocol: AI-HANDOVER/V2

Start here:

1. `STATE.yaml`: compact truth snapshot
2. `HANDOVER.md`: quick summary
3. `CURRENT_STATE.md`: detailed present state
4. `PENDING.md`: remaining work
5. `NEXT_AGENT.md`: continuation steps

Read only when referenced:

- `ISSUES.md`: open issues, failed approaches
- `TESTING.md`: verification evidence
- `PROJECT_CONTEXT.md`: goal, constraints, user preferences
- `DECISIONS.md`: pointers to `docs/DECISIONS.md` plus session decisions

Long-lived project docs stay where they are: `docs/CHANGELOG.md` (what
changed), `docs/DECISIONS.md` (D1-D15), `docs/TASKS.md`,
`docs/PHONE-TEST-CHECKLIST.md`, `docs/IMPLEMENTATION-PLAN.md`.
