# AtomicVault — Native Android Edition

## Technology

- Kotlin
- Jetpack Compose
- Material 3
- Android SDK
- SQLCipher
- Android Keystore
- BiometricPrompt
- Android Autofill Framework
- InputMethodService
- Coroutines
- Moshi

## Build instructions

For local development:
```bash
./gradlew assembleDebug
```

For production:
```bash
./gradlew assembleRelease
```
